# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, parser desynchronization, or denial-of-service vector within `php-ical-transition-rehearsal`, please report it responsibly by contacting Lofrano Tecnologia at `security@lofrano.com.br`.

Please include:
1. Detailed description of the vulnerability or edge-case bypass.
2. Minimal reproducing iCalendar (`.ics`) file or synthetic recurrence pattern.
3. Observed resolver behavior versus expected deterministic outcome.

We review incoming security reports promptly and deliver coordinated remediation.
